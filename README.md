# Алгоритмы и структуры данных на Java

Собственные реализации базовых структур данных и алгоритмов на Java, без использования
готовых коллекций из JDK. Каждая структура написана с нуля: своя работа с памятью,
свой итератор, свои проверки границ.

Учебный проект курса Academ IT School, сохранён как справочник и как показатель
того, что за `ArrayList` и `HashMap` из стандартной библиотеки я понимаю, что происходит.

## Что реализовано

| Модуль | Что внутри |
|---|---|
| `ArrayList` | Динамический массив: рост ёмкости, `trimToSize`, fail-fast итератор |
| `ArrayListHome` | Практическая задача на динамический массив, чтение данных из файла |
| `List` | Односвязный список: вставка и удаление по индексу, разворот на месте |
| `HashTable` | Хеш-таблица на массиве списков, разрешение коллизий цепочками |
| `Tree` | Двоичное дерево поиска: вставка, поиск, удаление узла, обходы в ширину и глубину |
| `Graph` | Граф: обходы в ширину и в глубину |
| `Vector` | Вектор произвольной размерности: сложение, вычитание, скалярное произведение, длина |
| `Matrix` | Матрица: умножение, транспонирование, определитель, произведение на вектор |
| `Range` | Числовой интервал: пересечение, объединение, разность |
| `Shapes` | Иерархия фигур, сравнение по площади и периметру через `Comparator` |
| `Lambdas` | Stream API и лямбды: фильтрация, группировка, агрегация |
| `Temperature` | Конвертер температур на Swing, разделение на Model / View / Controller |

## Стек

Java, JDK-коллекции только как эталон для сравнения, Swing в модуле `Temperature`,
сборка средствами IntelliJ IDEA (каждый модуль - отдельный `.iml`).

## Как запустить

В каждом модуле есть свой `Main` с демонстрацией работы структуры:

```bash
git clone https://github.com/van-create/Algorithms_and_DataStructures_java.git
```

Дальше открыть папку в IntelliJ IDEA и запустить `Main` нужного модуля.
Внешних зависимостей нет, достаточно JDK 17 или новее.
